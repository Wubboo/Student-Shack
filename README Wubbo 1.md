## Randvoorwaarden
* De website wordt gemaakt met React voor de frontend.
* De backend wordt ontwikkeld met Node.js en Express.js.
Er wordt gebruik gemaakt van een database voor het opslaan van kamergegevens.
* De website moet responsive zijn en werken op desktop, tablet en mobiel.
* Gebruikers moeten kunnen zoeken naar kamers via een zoekbalk en filters.
* De homepage moet overeenkomen met de gemaakte mock-ups en ontwerpen.
* De website moet een overzicht van beschikbare kamers tonen met behulp van kamerkaarten.
* De frontend en backend moeten communiceren via een API.
* De code wordt beheerd met Git en GitHub, waarbij gebruik wordt gemaakt van branches en merges.
